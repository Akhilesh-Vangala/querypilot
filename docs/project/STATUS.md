# Execution modes and evidence contracts

| Runtime | Execution | State |
| --- | --- | --- |
| Public file workspace | Reviewed aggregate; no model calls | Request-local processing; explicit device snapshots |
| Public investigation studio | Deterministic guided actions on synthetic claims/network data | Session-owned browser history |
| Private persistent runtime | Guided, scripted or configured SDK model transport | PostgreSQL admission, leases and owner-fenced workers |

The UI and reports identify their mode. `run-v1` correlates events and results and names the input/contract/result fingerprints, verification scope, producer version and billing origin. Report signatures authenticate retained artifacts. General SQL uses an execution-only receipt; reviewed comparisons use semantic reconciliation; public aggregates use declared-contract verification.
