# Design tradeoffs

- **Preserve the repository and original baseline.** The explicit user request authorizes improving QueryPilot. Preserve Git history, original tests/data and deterministic evaluator; build a new investigation API around them. Backend/frontend top-level folders follow the existing framework layout.
- **LangGraph for the inner agent loop.** A bounded graph makes tool/correction/publication stages explicit. Durable outer admission/events use PostgreSQL. No multi-agent swarm, Temporal dependency or MCP wrapper is added for appearance; SQL authority must remain application-owned. Persistent graph checkpoints are deferred because automatic paid replay is not implemented safely yet.
- **SQLGlot plus database authority.** AST scope handles syntax/CTEs/quoted identifiers better than regex. The dedicated role/read-only transaction enforces an independent database boundary. Neither proves arbitrary business correctness.
- **Official synchronous SDK in a synchronous worker.** FastAPI synchronous handlers run through its thread pool; paid generation happens in a separate worker process. SDK function schemas are native and strict; Pydantic validation remains local. No blocking SDK call is placed directly in an async endpoint. Generation retries are disabled to avoid hidden paid replays.
- **Safe visible summaries.** Final numbers derive from executed rows. Model prose is not displayed as an unchecked factual interpretation. The public plan is an inspectable proposal, and execution receipts expose the result's practical limits.
- **Vercel for the demonstration, containers/Postgres for durable execution.** The demo is genuinely interactive over synthetic data, with explicit browser-session history. Ephemeral serverless state is not called a persistent production backend. Provider selection requires actual account inputs.
- **Conservative failure recovery.** Expired or shutdown ownership cannot publish. Interrupted work requires explicit new admission, rather than silently rerunning model requests. This sacrifices automatic mid-run recovery to keep costs and publication behavior clear.
- **Authentication foundation, enterprise identity deferred.** HttpOnly cookies, database-backed users/roles and owner-scoped histories improve the original token-localStorage design. OIDC, JWT revocation and organization warehouse permissions remain release gates.
